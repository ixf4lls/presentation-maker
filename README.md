# 🎨 Presentation Maker

SPA-приложение (аналог PowerPoint) на React/Redux/TypeScript для создания и редактирования презентаций прямо в браузере. Прототип с базовым набором функций: управление слайдами, добавление и перемещение элементов.


  ![image](https://github.com/user-attachments/assets/bc1b7b27-cd65-4340-af88-cd855fa0121e)

## ⚙️ Технологии

- React
- Redux
- TypeScript
- Vite

## ✨ Возможности

- Создание, редактирование и удаление слайдов
- Добавление элементов на слайд (фигуры, текст и т.п.)
- Поиск и загрузка картинок с стороннего сервиса [Unsplash](https://unsplash.com/)
- Перемещение и изменение размеров элементов
- Управление историей действий (undo/redo)
- Сохранение/загрузка презентации через JSON
- Экспорт презентации в PDF
- Работа полностью на клиенте, без бэкенда

## 🔨 Установка и запуск

```bash
git clone https://github.com/exesakreda/presentation-maker
cd presentation-maker/app
npm install
npm run dev
```
После запуска откройте адрес из консоли (например, http://localhost:5173).
